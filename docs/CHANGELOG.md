### 신규 참가자 첫 로그인 500 수정 (포트폴리오 경쟁 상태)
`ensurePortfolio` 가 "읽어보고 없으면 만든다" 였다. 첫 로그인 직후에는 포트폴리오·체결이력·
리더보드 조회가 한꺼번에 들어오는데, 둘 이상이 동시에 "없다"고 판정하면 양쪽이 `create` 를
쏘고 늦은 쪽이 유니크 위반(P2002)으로 **500** 을 받았다 — 첫 화면이 깨지는 자리다.
- 유니크 위반을 정상 경로로 취급한다: "남이 먼저 만들었다"는 뜻이므로 그 행을 다시 읽어
  돌려준다. 제약이 "시즌당 1개"를 보장하므로 재시도가 아니라 재조회로 끝난다.
- 순위 재계산(`onPortfolioChanged`)은 **만든 쪽만** 부른다(이긴 쪽이 이미 불렀다).
- 위반이 아닌 에러, 그리고 위반인데 행도 없는 경우는 삼키지 않고 올린다.
- 회귀 spec 5개 추가(수정을 되돌리면 2개가 실패하는 것으로 유효성 확인). 실제로도 동시 요청
  8건으로 재현해 경쟁 5회가 모두 정상 처리되는 것을 확인했다.

### 화면 구조 개편 — 메인 통합·프로필 드롭다운·선택 종목 즉시 주문
메뉴가 10개로 불어나 "어디서 무엇을 하는지"가 흐려졌다. 진입점을 셋으로 정리한다 —
**로고**(메인), **상단 네비**(탐색), **프로필 드롭다운**(내 화면).
- **메인 통합**: "실시간 시세 대시보드"와 "인기 종목"은 둘 다 표에서 종목을 골라 옆 차트를
  보는 화면이라 `/`(index) 하나로 합쳤다. 메뉴 항목은 없애고 **좌측 상단 로고**가 여기로
  돌아온다. 통합 전 두 경로는 메인으로 리다이렉트한다(북마크 보호).
- **프로필 드롭다운**: 내 포트폴리오·내 프로필·잔고·손익·주문·이력 + 로그아웃을 우측 상단
  프로필 버튼에 모았다. 상단 네비에는 리더보드·종목 탐색·관심종목만 남는다.
  상시 노출이 필요한 값(SCORE/HI-SCORE·MOCK/REAL 배지)은 헤더에 그대로 둔다.
- **선택 종목 즉시 주문**: 종목을 고를 수 있는 세 화면(메인·종목 탐색·관심종목)에 차트와
  함께 **페이퍼 매매 주문 창**을 배치하고, 고른 종목을 프리필한다. 표는 `{code, name}` 을
  올려보내고(`SelectSymbol`) 페이지가 차트·주문 폼에 내린다. 실계좌 주문은 오조작 위험이
  커서 기존 `주문·이력` 화면에만 남긴다.
- **차트에 종목명 표기**: 코드만 찍히던 차트 헤더·패널 제목에 종목명을 띄운다. 이름은 고른
  표의 행에서 함께 넘어오므로 추가 조회가 없다.
- **시가총액 순 정렬**: 순위표에 `시가총액` 탭 추가. 키움에 국내 시가총액 순위 TR 이 없어
  종목 마스터의 `상장주식수 x 전일종가`로 파생해 `SymbolCache` 에 저장하고 DB 가 정렬한다
  (키움 추가 호출 0). **전일 종가 기준**이므로 장중 순위가 움직이지 않고 전일대비는 비어
  있다 — 화면에 기준을 함께 표기한다. ETF 제외.
  - `SymbolCache` 에 `lastPrice`·`listCount`·`marketCap` 칼럼 추가(마이그레이션).
    파생 칼럼이 없던 캐시는 TTL 안이어도 다시 받는다(자동 복구).

### 종목명 검색 + 관심 ★ 낙관적 갱신
종목코드를 외우고 있는 사용자는 없다. 코드만 받던 입력을 **종목명 자동완성**으로 바꾸고,
★ 토글은 서버 왕복을 기다리지 않고 즉시 반영한다.
- `GET /api/market/symbols/search?keyword,limit`(공개) — 코스피·코스닥·ETF 통합 검색.
  BFF 의 `SymbolCache` 를 질의하므로 유량을 태우지 않고, 관련도 순으로 정렬한다
  (코드 완전일치 → 이름 앞부분 → 중간 포함). 마스터 캐시는 부팅 시 배경에서 데운다 —
  ka10099 페이지네이션은 분 단위라 검색 요청 경로에 두지 않는다.
- 적용된 입력: 관심종목 추가(대시보드·관심종목 페이지, 공용 `FormAddWatch` 로 통합),
  주문 폼, 페이퍼 매매 폼. 종목 탐색 표의 검색은 이미 이름·코드 양쪽을 지원했다.
  **코드를 그대로 붙여넣는 기존 사용법은 그대로 통한다.**
- 종목이 확정되기 전에는 제출 버튼이 잠긴다 — 코드를 잘못 외워 다른 종목에 주문을 내는
  것이 가장 비싼 실수다.
- ★ 토글은 낙관적 갱신(`onMutate` 로 캐시 선반영, 실패 시 롤백). 토글이 여럿 겹치면
  마지막으로 끝나는 응답만 캐시를 확정한다(응답 역전으로 ★ 가 되살아나는 것 방지).
