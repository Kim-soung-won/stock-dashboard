# WebSocket (실시간 시세 / 조건검색)

> 자동 생성 문서 — `scripts/build_reference.py` 로 재생성. 요청/응답 필드 전체는 `python scripts/kiwoom_spec.py show <apiId>` 로 확인.


접속: `wss://api.kiwoom.com:10000/api/dostk/websocket` (모의 `wss://mockapi.kiwoom.com:10000`), 미국주식은 `/api/us/websocket`.

스펙 JSON에는 **메시지 페이로드만** 정의되어 있다. 접속 직후의 LOGIN 핸드셰이크와 PING/PONG 유지 규약은 `reference/conventions.md` 의 WebSocket 절 참고.

## 실시간 등록/해지 메시지 (모든 실시간 타입 공통)

```json
{"trnm":"REG","grp_no":"1","refresh":"1","data":[{"item":["005930"],"type":["0B"]}]}
```

- `trnm`: `REG` 등록 / `REMOVE` 해지
- `grp_no`: 그룹번호(4자리) — 그룹 단위로 등록/해지 관리
- `refresh`: `1` 기존 등록 유지(기본), `0` 기존 등록 해지 후 교체
- `data[].item`: 종목코드/업종코드 배열 (거래소 구분: `039490`, `039490_NX`, `039490_AL`)
- `data[].type`: 실시간 타입 코드 배열 (아래 표)

수신 메시지는 `{"trnm":"REAL","data":[{"type":"0B","name":...,"item":"005930","values":{"<FID>":"<값>"}}]}` 형태이고, `values` 의 키는 아래 각 타입의 FID 번호다.
